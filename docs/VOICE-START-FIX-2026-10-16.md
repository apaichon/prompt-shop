## Repeatable local startup

Use `rtk proxy make mvp-start`, `mvp-status`, `mvp-restart` and `mvp-stop`; see [initial testing](INITIAL-TESTING.md). Existing infrastructure-only `make start` still starts PostgreSQL, not the voice services. The full launcher loads the separate private env files, checks the pinned offline model, builds the app, starts Laya → ADK → Go, and keeps logs/PIDs under ignored `tmp/run/`. It refuses to signal a foreign process if a saved PID is reused.

Laya's frozen 19/40 accuracy and the missing canonical fixture cases remain unchanged. One synthetic native flow does not qualify all English turns, interruption/recovery, five-user load, final audible grounding, protected backoffice or cloud/release gates. Historical task/test evidence remains attributed to its original source; no task or full acceptance test is marked passed by this fix.
