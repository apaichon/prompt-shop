# Early GCP English vertical-slice smoke

Proposed specification; no execution. Gate early staging on 14 October 2026 Asia/Bangkok after TASK-0002/0003/0004 and TASK-0010 have integrated. It does not require TASK-0009 backoffice, final release/rollback, the full benchmark or submission package.

## Setup
Use the approved GCP project/budget/access configuration, HTTPS staging URL, one immutable revision with Go ingress, Python ADK and Laya container image digests plus persistent PostgreSQL seed. Record device/browser/network, actual `gemini-3.8-live` setup/provider identity, PCM formats and fixture versions. Retain this verified revision as a possible known-good baseline.

## Steps
1. Open the staging URL in a fresh supported browser; verify static portal, /healthz and /readyz and record serving revision. Prove the chosen reviewer access flow actually works; confirm the ADK and Laya private listeners are not publicly routable and bridge startup/health is qualified.
2. Start voice and use the mandatory ADK `Runner.run_live()` runtime to stream actual bidirectional PCM (16 kHz input/24 kHz output) to `gemini-3.8-live`. Speak an item request, invoke actual Laya classification through ADK before receiving read-only catalog-tool results with grounded audio and verified cards, speak a clarification/selection, and receive route-tool facts with voice and map. Audit audible and displayed shelf assertions against tool facts. Required-model, Laya classifier or ADK-runtime unavailability blocks this gate; typing, mocks or another speech pipeline or raw Gemini bypass of ADK cannot pass.
3. Deny microphone permission and verify usable typed recovery; query an unknown item and confirm no invented shelf in voice or UI. Interrupt a playing response and confirm old audio stops. Disconnect and restart explicitly; ensure old events cannot change the result, queue/session cleanup occurs, and a new ADK run uses fresh transient state. Distinguish tool failure from item-not-found. Inspect representative assets/logs for secrets, raw audio and transcript content.
4. Restart/replace the container and verify database seed/counts and the same item lookup persist. Observe one cold session setup separately, setup30s/session300s/idle60s and Cloud Run360s bounds, error behavior, process memory and configured limits; no percentile claim follows from a single smoke.

## Expected
Reachable HTTPS, real English end-to-end flow, persistent catalog, safe recovery/logging and recorded evidence by the 14 October smoke milestone. Save URL/revision, device/configuration, redacted smoke captures, persistence comparison and known-good image reference. A hello-world page, mocks or a typed-only flow fail this gate.
