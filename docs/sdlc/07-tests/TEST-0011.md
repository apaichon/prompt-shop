# Rehearsal and submission-package readiness

Proposed specification; no execution. This separate gate is due 17 October 2026 Asia/Bangkok, after the 16 October release. Submission is 18 October after user review. It is not a prerequisite to the earlier deployment gate.

## Setup
Use the accepted release URL/image/revision from TEST-0004, final presenter device/network, approved reviewer access and a submission checklist with required format/channel and exact cutoff confirmed. Prepare walkthrough, backup recording, screenshots and setup/runbook.

## Steps
1. Rehearse ADK `Runner.run_live()` with `gemini-3.8-live` native voice-to-voice on the deployed URL: Start voice, speak an item, verify real Laya classification through ADK, hear grounded catalog-backed clarification, speak a selection, and receive spoken directions plus verified shelf/map. Demonstrate barge-in and an unknown item, distinguishing tool errors from not-found. Confirm actual model identity; an unavailable model or alternate speech pipeline or raw Gemini bypass of ADK cannot qualify the recorded demo. Demonstrate one authorized backoffice draft→publish→shopper search and logout protection.
2. Record a 2–3 minute walkthrough on the verified revision. Check backup playback, sound, readable shelf/map labels and a clear recorded-demo designation. Screenshots/video must contain no credentials or source-project private data.
3. Open setup/runbook, architecture/reuse references and release links as a reviewer. Verify URL, source/image revision, sample-data limits, entrance origin and supported/disabled locales match deployment; check sharing permissions and reproducible setup steps.
4. Check each submission deliverable against required format/channel, confirm exact 18 October cutoff and named submitter, and present the package for user review. Do not send/upload an external submission as part of this test.

## Expected
A reproducible rehearsed demonstration, working backup video, accurate setup/runbook/release references and complete submission checklist on 17 October. Preserve artifact paths, hashes or revision references, playback/access observations and review checklist. Missing required package assets fail this gate without retroactively changing the earlier release result.
