# Test: Embedding router label gate

## Setup

Use the agent test environment and `agent/tests/test_embedding_router.py`. The embedder is a fake or an `httpx` mock. Do not call the Gemini API. Do not set `INTENT_BACKEND` for the existing Laya shopper-tool tests. Load the prototype file and the 40-sentence eval file from `agent/tools/prototypes/`.

## Steps

1. Score hand-built vectors. Confirm the nearest eligible label wins, a margin below 0.15 abstains, and confidence below 0.70 abstains with scores.
2. Drop `select_item` when the session has no results and drop `repeat_directions` when it has no route. Confirm a selection-shaped vector cannot win a route in that state.
3. Run `ShopperTool` with a `gemini-embedding-2` revision. Confirm `out_of_scope` and abstain make zero catalog, route, and summary calls and still allow audio. Confirm find, select, repeat, and summarize each call only their allowed tool.
4. Build the batch embed request. Confirm the classification prefix, 768 dimensions, header key, and the absence of `task_type` and of the shopper sentence in logs.
5. Confirm the eval file has 40 disjoint sentences, eight per label, and that the Laya `result()` checker still rejects `summarize` and a non-Laya revision.
6. Run the existing agent shopper-tool tests with the fixture revision `contract-fixture` and confirm their catalog calls stay unchanged.

## Expected

The new module tests pass. The Laya default path still searches and routes as it does today. No test reports a live 36-of-40 embedding score. No test rewrites the Laya 19-of-40 result.
