# Go ADK compatibility verification

Run actual ADK Runner.RunLive against a local WebSocket fixture. Capture the
configured model/voice, audio/transcript/manual-activity settings, input PCM and
tool responses. Exercise completion and cancellation. Characterization tests may
pass while proving an SDK omission; feasibility is reported independently.

Run an opt-in bounded configured-model probe with private credentials, synthetic
speech and a non-catalog acknowledgment tool. Output contains counts/status only.
Provider error details, audio and transcripts are not release evidence artifacts.

## Executed results — 18 October 2026

`rtk proxy env GOMAXPROCS=2 make test vet build` from agent-go passes against the
explicit SDK compatibility workspace: six configuration subcases, two actual
Runner.RunLive wire cases, cancellation/socket cleanup, missing credentials and
strict acknowledgment-tool arguments. `go test -race`, `go vet` and build pass.
The wire cases also check interruption events, mixed caption/audio/completion,
blocking tool response, manual activity configuration, modern text/audio fields
and absence of legacy media chunks for the configured 3.8 model.

Stock ADK v2.6.0 / GenAI v1.74.0 does not qualify: actual setup omits the manual
activity setting, race tests observe concurrent SDK writes, and a real synthetic
manual-PCM run timed out at 55 seconds with zero tool calls/transcripts/audio.
The stock text-controlled probe did pass. A two-patch intermediate run failed
with provider close code 1007 while the modern input mismatch remained unresolved.
These failed observations remain in the evidence bundle.

With all three versioned compatibility patches, the configured `gemini-3.8-live`
and `Aoede` probe passes:

| Input | Tool calls | Input/output captions | Output PCM | Nonzero samples | Completion / cleanup | Elapsed |
|---|---:|---|---:|---:|---|---:|
| Synthetic 16 kHz manual PCM | 1 | Both present | 89760 bytes | 44126 | Both pass | 5670 ms |
| Text control | 1 | Output present; input caption not required for text | 42242 bytes | 20037 | Both pass | 2688 ms |

Elapsed includes connection, input and whole response, not first-actionable-audio
p95. The tool acknowledges only; it cannot supply catalog facts. There is no
physical microphone/speaker, browser route, thirty-turn parity or load claim.

The CLI rejects a missing native opt-in before a provider call. The SDK workspace
integrity check rejects a deliberate extra-file mutation and accepts the restored
tree. Module/cache files remain original; full patched-tree and patch hashes are
recorded in the generated manifest.
