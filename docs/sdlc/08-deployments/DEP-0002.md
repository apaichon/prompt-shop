# v0.2.0 source checkpoint

The user requested commit, push and a version tag before planning a new UI from
their supplied Monti Store reference. Product source was already committed and
pushed on main `b5a17baab12d528eb6712e3db429cb97b67160de`. This release branch adds
only the version ledger; the annotated tag identifies its merge into main.

This is a local prototype source version, not a deployment execution or acceptance
approval. No image, Cloud Run revision, database change or cloud rollout is created.
Existing task/test statuses and the failed frozen classifier benchmark remain intact.

## Included behavior

- All ten task source trees integrated; PostgreSQL lifecycle and repeatable full
  local MVP start/stop/restart/status commands.
- Configurable Gemini model and voice, private ADK/Laya services and least-privileged
  catalog/ticket access.
- Published catalog search, store map and stored-edge route lookup connected to
  the public portal and native voice gateway.
- Native audio pacing, conversational greetings/general questions/meal ideas,
  and per-turn selection of conversation versus catalog lookup.

## Existing executed evidence

The [conversation repair record](../../VOICE-CONVERSATION-FIX-2026-10-16.md) identifies
the candidate evidence and remaining limits. Following merge, the same four-turn
synthetic browser flow was repeated against main `b5a17ba`: greeting, arithmetic,
meal suggestion and whole-milk route all completed with native audio, matching
stored aisle/shelf captions, no early catalog call, error, backlog or socket close.
The scoped checks passed: 39 ADK/adapter/launcher tests, race-enabled Go voice/config
checks and vet, 29 web unit tests, Svelte check/build and 36 offline QA tests.

These do not qualify physical-device listening, 30-trial latency, frozen classifier
accuracy, complete backoffice/cloud acceptance or release promotion. Laya remains
19/40 against the required 36/40. Included source is not a claim that its task is done.

## Recovery and redesign baseline

Retain the immutable tag as the pre-redesign reference. Compare future UI changes
against this source and the existing native voice behavior. Use an isolated worktree
to inspect/build the tag. A rollback that changes shared main uses reviewed revert
commits or a new release; never move/delete this tag or force-push shared branches.

No runtime restart is needed for this documentation-only checkpoint. The redesign
plan and avatar work will be later commits, outside this baseline tag.
